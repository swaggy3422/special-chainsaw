FUND.GO/EDD website

Files:
- index.html: main website page
- catalog.js: directory data (700 game directory entries and 150 app/service links)
- README.txt: these instructions

To publish with GitHub Pages:
1. Extract this ZIP.
2. Upload index.html, catalog.js, and README.txt to the ROOT of your GitHub repository.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish the site.

This is a directory of links, not 700 separately developed games. It does not provide a proxy or bypass network restrictions. Follow school and network rules.
